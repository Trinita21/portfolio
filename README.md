This is the github for my portfolio website. It is a work in progress!

Live site: https://trinita21.github.io/portfolio/

The site is plain HTML/CSS in [`docs/`](docs/), served by GitHub Pages (Settings → Pages → `main` branch, `/docs` folder). To add a note, drop the PDF in `docs/notes/` and copy a `<details>` block in `docs/notes.html`. The older Streamlit version is in `portfolio_website/`.
